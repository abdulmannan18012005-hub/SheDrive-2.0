# PRD: SheDrive 2.0

## Project Specifications
SheDrive 2.0 is a female-only ride-hailing platform built for safety, reliability, and modern user experience.

## User Personas
- **Passenger**: Female riders seeking safe, reliable transportation.
- **Driver**: Female drivers seeking flexible earning opportunities.
- **Admin**: System administrators managing the platform, support, and safety.

## Safety Mandates
- Strict female-only verification.
- Emergency SOS integration.
- Ride tracking and sharing.

## Functional Specs
- Real-time ride hailing and matching.
- In-app chat and notifications.
- Trip receipts and history.
- Driver verification and approval flow.
- Admin dashboard for monitoring and support.
